Как добавить реквизит

Карта должна попасть в трансгран KZT (C2CKZT). Для этого в форме выбираете свой банк, не C2CKZT.

Какой банк выбрать

Мерчант шлёт C2CKZT. Вы выбираете банк — это имя уйдёт клиенту в поле bank.

Elkard Kompanion Mbank Optima O bank Bai-Tushum
Если выбрать C2CKZT, поле банка у мерчанта будет пустым. Всегда выбирайте банк из списка выше.
Вы: Elkard / Mbank / …
→
Роутинг C2CKZT
→
Клиент видит карту + bank

Профиль

В правом верхнем углу — ваш email. Оттуда выход из аккаунта.

Кабинет you@email →
💬
Смена почты, пароля, 2FA, телефона и данных профиля — только через рабочий чат. Напишите команде, что нужно поменять. Самостоятельно в кабинете эти поля не редактируются.

Пополнение баланса

Для выдачи карт на трансгран на балансе должен быть USDT (роутинг проверяет покрытие суммы).

💬
Пополнение USDT производится через рабочий чат. Не переводите средства на адрес из кабинета, пока сумма, сеть и адрес не подтверждены в чате. После зачисления команда подтвердит баланс — можно принимать заявки.
Вывод средств — тоже через рабочий чат, если иное не согласовано с командой.

Рабочий чат

Один канал с командой для всего операционного:

  • пополнение и вывод USDT;
  • правки профиля (почта, пароль, 2FA);
  • новые банки / лимиты / блокировки карт;
  • спорные заявки и апелляции.

В чат пишите: что сделать, сумму (если перевод), и ID группы/карты, если вопрос про реквизит.
